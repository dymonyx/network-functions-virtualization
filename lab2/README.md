# Лабораторная работа №2. Настройка маршрутизатора SONiC в GNS3 и построение простой сети

## Создание топологии

В GNS3 был создан новый проект, в котором была собрана сеть из одного маршрутизатора SONiC, двух коммутаторов и двух хостов VPCS.

Топология сети:

```text
PC1 — Switch1 — SONiC — Switch2 — PC2
```

Для каждого сегмента сети была выбрана отдельная подсеть.

### Сегмент 1

- Сеть: `10.10.1.0/24`
- PC1: `10.10.1.10/24`
- Шлюз PC1: `10.10.1.1`
- SONiC Ethernet0: `10.10.1.1/24`

### Сегмент 2

- Сеть: `10.10.2.0/24`
- PC2: `10.10.2.10/24`
- Шлюз PC2: `10.10.2.1`
- SONiC Ethernet4: `10.10.2.1/24`

Таким образом, маршрутизатор SONiC соединяет две различные подсети и обеспечивает маршрутизацию между ними.

## Подключение к SONiC

После запуска виртуального маршрутизатора была открыта его консоль.

Для входа использовались стандартные учётные данные SONiC:

```text
Login: admin
Password: YourPaSsWoRd
```

После успешной авторизации была выполнена настройка сетевых интерфейсов.

## Настройка SONiC

Сначала было проверено состояние сетевых интерфейсов:

```bash
show interfaces status
```

Для подключения двух сегментов сети были использованы интерфейсы `Ethernet0` и `Ethernet4`.

Интерфейсу `Ethernet0` был назначен IP-адрес из первой подсети:

```bash
sudo config interface ip add Ethernet0 10.10.1.1/24
```

Интерфейсу `Ethernet4` был назначен IP-адрес из второй подсети:

```bash
sudo config interface ip add Ethernet4 10.10.2.1/24
```

После настройки была выполнена проверка назначенных IP-адресов:

```bash
show ip interfaces
```

Для сохранения конфигурации SONiC была выполнена команда:

```bash
sudo config save -y
```

## Настройка PC1

Для первого хоста был установлен IP-адрес `10.10.1.10/24`, а в качестве шлюза по умолчанию был указан интерфейс маршрутизатора SONiC `10.10.1.1`.

```text
ip 10.10.1.10/24 10.10.1.1
```

Настройки хоста были проверены командой:

```text
show ip
```

После этого была проверена доступность шлюза:

```text
ping 10.10.1.1
```

Конфигурация VPCS была сохранена:

```text
save
```

## Настройка PC2

Для второго хоста был установлен IP-адрес `10.10.2.10/24`, а шлюзом по умолчанию стал второй интерфейс SONiC `10.10.2.1`.

```text
ip 10.10.2.10/24 10.10.2.1
```

Настройки были проверены:

```text
show ip
```

После этого была проверена доступность шлюза:

```text
ping 10.10.2.1
```

Конфигурация второго VPCS также была сохранена:

```text
save
```

## Проверка сетевого взаимодействия

После настройки обоих сегментов была выполнена проверка связи между хостами через маршрутизатор SONiC.

С PC1:

```text
ping 10.10.2.10
```

С PC2:

```text
ping 10.10.1.10
```

Успешное прохождение ping подтвердило, что маршрутизатор SONiC корректно выполняет маршрутизацию между сетями `10.10.1.0/24` и `10.10.2.0/24`.
